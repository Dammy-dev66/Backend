# Finbar B. Elite Tutoring: Customer Copy Review

This is the complete customer-facing message set for the tutoring flow. The proposed text is ready to apply after Finbar approves it.

## 1. Package purchase receipt

**Email subject**

`Finbar B. Elite Tutoring | Your [subject] package receipt`

**Heading**

`Your package is confirmed.`

**Intro**

`Thank you for your purchase. Your package code is below. Keep this email so you can return whenever you are ready to book your remaining sessions.`

**Code helper text**

`Your package code is unique to this subject and package. Use it when booking any remaining sessions.`

**Button**

`Book package sessions`

**Below-button note**

`The button remembers the details from this purchase. You can review or change them before confirming your sessions.`

## 2. Payment return page

**Heading**

`Your payment was received.`

**Body**

`Your package receipt, including your package code and a link to book sessions, has been sent to your email address.`

**Button**

`Continue to booking`

## 3. Package session selection

**Eyebrow**

`Book package sessions`

**Balance helper**

`Choose up to [remaining] session[s] from your package.`

**Partial booking prompt**

`You have selected [selected] of [total] sessions. [remaining] session[s] will remain in your package. Would you like to confirm these sessions now and book the rest later?`

**Buttons**

`Confirm these sessions` and `Choose more times`

## 4. Saved details confirmation

**Heading**

`Review your booking details.`

**Body for a returning package customer**

`We have filled in the details from your package purchase. Please check them and update anything that has changed before confirming your sessions.`

**Primary button**

`Confirm package sessions`

## 5. Package booking confirmation

**Heading when sessions remain**

`Your sessions are confirmed.`

**Body when sessions remain**

`[booked] session[s] have been confirmed. You have [remaining] session[s] remaining in this package. Your receipt email includes a button to return when you are ready to book them.`

**Body when package is fully used**

`All sessions in this package are now confirmed. A booking confirmation has been sent to your email address.`

## 6. Standard single-session booking confirmation

**Email subject**

`Finbar B. Elite Tutoring | Booking confirmed for [subject]`

**Heading**

`Your lesson is confirmed.`

**Body**

`Thank you. Your lesson time is confirmed and the booking details have been sent to your email address.`

## 7. Package-code messages

**Field label**

`Package code`

**Field helper**

`Enter the code from your package receipt. No email address is needed.`

**Invalid-code message**

`We could not find an active package for that code. Please check the code in your receipt email and try again.`

**No remaining sessions message**

`This package has no sessions remaining. Please choose a new booking option or contact Finbar if you think this is incorrect.`

## Internal notification for Finbar

**Subject**

`New tutoring booking | [subject] | [date and time]`

**Include**

- Parent/guardian name, email, and phone
- Student 1 and Student 2 names, where applicable
- Subject, lesson format, package type, and price
- Booked date(s), time(s), and timezone
- Notes or learning goals
- Package code and sessions remaining, when relevant

The customer receipt should not include student names.
